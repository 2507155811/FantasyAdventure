# 经典横版动作 RPG 参考与原创重制方案

## 目标

项目早期以《小红帽穿越记》作为玩法体验参考，优先复现经典横版动作 RPG 的操作节奏和系统完整度，再逐步扩展为原创游戏。

## 可借鉴并独立实现的玩法规律

以下属于高层次玩法设计方向，应由本项目自行编写代码、制作数值和关卡：

- 横版关卡推进、检查点、普通关卡与首领关卡的节奏
- 角色移动、跳跃、闪避、普通攻击、连招和技能释放
- 怪物的巡逻、追击、攻击前摇、受击、击退和死亡行为
- BOSS 的阶段切换、攻击预警、技能循环和弱点窗口
- 角色升级、属性成长、装备槽位、掉落概率与稀有度
- 药水、技能冷却、金币和材料等资源循环
- 关卡奖励、任务、商店、背包和图鉴等常见 RPG 系统
- 战斗 HUD 的信息层级与便捷操作原则

实现时要根据本项目的双武器、自由操作、离线存档等已确认设计做适配，而不是逐项机械复制。

## 必须原创或取得授权的内容

不得直接复制或提取原游戏的：

- 关卡地图文件、地图布局、背景与地形贴图
- 角色、怪物、NPC 的立绘、模型、动作帧和动画
- 武器装备图标、UI 美术、特效、字体素材
- 音乐、音效、剧情文本、对话和独特角色设定
- 原游戏代码、资源包或其他受保护文件

将原图放大、锐化、重绘或使用 AI 高清化，并不当然取得素材使用权。若确实拥有明确授权的素材，应记录授权来源和许可范围。

## 高清原创美术制作标准

- 先建立角色正面、侧面、背面设定，固定比例、服装、发型和配色。
- 为每个角色制作独立动作清单：待机、跑步、跳跃、下落、攻击、技能、受击、闪避、倒地/退场。
- 地图采用可复用的原创地形模块和多层视差背景。
- 统一光照方向、描边、阴影、色彩范围和像素/绘制风格。
- 透明背景角色素材按统一画布尺寸、锚点和命名规则导出。
- UI 重新绘制，保留清晰的信息层级，不复刻原作独特图形细节。

## 开发顺序

1. 先实现可玩的移动、攻击、受击和一个普通怪物。
2. 再实现一段原创短关卡，验证横版镜头、地形碰撞和战斗节奏。
3. 加入精英怪与一个具有阶段机制的 BOSS。
4. 加入掉落、装备、属性成长、药水和存档。
5. 扩展章节、支线、隐藏区域、图鉴和完整 UI。
6. 最后统一替换/完善高清原创美术并在 Android 真机测试。

## 原型验收原则

先验证玩法是否好玩、操作是否顺手、手机运行是否稳定，再批量生产高清素材。不要在核心玩法尚未验证前一次性制作大量最终美术。
