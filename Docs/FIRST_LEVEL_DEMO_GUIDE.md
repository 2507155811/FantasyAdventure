# 第一大关：森林净化

## 内容

同一连续关卡内包含森林入口、林间古道、守卫遗迹三个区域。角色向右探索，经过高台与十一只苔叶史莱姆，最终挑战古树守卫。没有解谜与宠物系统。

- 到达区域边界会保存检查点，恢复生命和魔法。
- 失败后可点击返回检查点，无需从头开始；本次运行已击败的敌人保持消失。
- 首领有重击蓄力，低于半血后攻击频率提升。
- 击败首领获得额外 100 金币，并显示通关界面，可查看装备或重玩。
- 金币、经验、武器品质、当前装备和检查点本地保存；重新启动应用时普通敌人重新生成。

## 简化操作

- 左右方向按钮移动。
- 跳跃、攻击、技能三个战斗按钮；攻击可按住。
- 魔法每秒自动恢复 3 点，技能消耗 15 点，冷却 4 秒。
- 生命低于 35% 且仍然存活时自动消耗红药，检查点补充至少两瓶。
- 键盘：A/D 或左右箭头移动，Space 跳跃，J 攻击，K 技能。
- 装备菜单暂停游戏，角色只装备一把武器，不在战斗中切换双武器。

## 武器

剑：快速近战与剑气；锤：慢速重击与周围冲击；长枪：长距离刺击；法杖：远程魔弹与前方范围魔法。
所有四类可在装备菜单选择，适合首关体验。金币可升级当前武器品质，四档外形来自同一武器图集。角色等级提升攻击数值，每四级推进一个外观阶段；品质决定特效色调。同一武器家族不因品质改变核心技能机制。

## 生成与构建

需要 Unity 6000.0.40f1，Android Build Support（含匹配的 SDK、NDK、OpenJDK）。
编辑器菜单 Fantasy Adventure → Build Demo Level 生成 Assets/Scenes/ForestStage01.unity。Android 构建方法 FantasyAndroidBuild.Build 会生成该场景并输出 build/Android/FantasyAdventure.apk，应用版本 0.2.0。

GitHub Actions 使用仓库 Secrets 授权构建，成功后在 Android APK Build 运行页底部下载 FantasyAdventure-Android-APK。
