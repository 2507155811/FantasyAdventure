# 《幻想冒险：异世界之旅》制作交接记录

更新时间：2026-11-14

这份文档用于在更换 ChatGPT 账号后继续项目。请新账号先阅读本文件及仓库 README、Docs 下的项目文档，再继续制作。

## 一、项目目标

- 项目名称：幻想冒险：异世界之旅
- 类型：原创 2D 横版动作 RPG
- 引擎：Unity 6（项目版本记录为 6000.0.40f1）
- 首要目标：完成一个可在安卓手机上演示的高品质第一关，并最终提供可安装 APK。
- 玩法参考经典横版动作 RPG 的操作与战斗体验；只借鉴类型玩法，不复制《小红帽穿越记》的角色、素材、地图、剧情或其他受版权保护内容。
- 游戏为单机离线体验，不做解谜，不加入宠物系统。

## 二、已经确认的设计要求

### 画面与角色
- 高清、精致的卡通奇幻横版风格。
- 主角造型方向：金色短发、红色兜帽、红披风、白色裙装、棕色皮革腰带与长靴、花篮。
- 横屏，适配 16:9、18:9、19.5:9、20:9 等比例；UI 注意安全区域，超宽屏可扩展视野。
- 画面风格需统一，角色、怪物、场景、UI、特效不能各自风格割裂。

### 操作与战斗
- 左侧虚拟摇杆。
- 右侧普攻、强攻、技能、必杀等按键。
- 支持跳跃、下蹲/下落、闪避、连招、跳跃攻击、技能组合、击飞击退和 Boss 阶段机制。
- 双武器系统，可在战斗中切换，技能动作随武器改变。
- 计划武器包括单手剑、双手剑、双刀、法杖、弓箭、长枪、巨锤、双手镰刀等。
- 战斗界面底部有红色生命药水与蓝色魔法药水，玻璃瓶质感，液位随数值变化；药水有数量限制与冷却。

### RPG 系统
- 力量、敏捷、体力、智力属性与自由加点，可用道具重置。
- 固定与随机装备掉落；基础属性加随机词条；装备外观/幻化。
- 主线独立横版关卡、隐藏地图、精英/Boss 副本、自由探索区域。
- 自动难度调节要克制：失败后轻微降低，通关后轻微增加，不可无限追随玩家等级强化怪物。
- 自动存档、手动存档、多个存档槽、本地离线存档。
- 怪物图鉴、装备图鉴；主线、隐藏故事、支线和多结局。

## 三、素材质量要求（用户特别强调）

用户明确要求：**不要使用简易素材或占位素材；不行就先制作图片让用户确认。**

因此：
- 禁止把色块、几何图形拼成的临时角色或怪物作为正式素材交付。
- 禁止用临时色块地面、临时背景或重复占位图冒充正式关卡美术。
- 不得声称高清角色、动作序列、骨骼动画、怪物动画、特效或音效已经完成，除非仓库中确实存在并已验证。
- 先制作高质量美术概念图给用户确认，再按确认方向制作可用于游戏的分层素材、Sprite Sheet/逐帧动画、图标和场景资源。
- 概念图不等于游戏内可直接使用的动画素材；需进一步切图、统一尺寸/锚点、整理动画帧并接入 Unity。
- 先确认主角设计，再确认怪物与 Boss，再确认第一关场景和 UI，最后批量制作并集成。
- 不要仅替换封面图就称美术完成。

## 七、给接手账号的明确执行顺序

1. 先检查仓库最新提交、Actions 最新运行状态和 APK artifacts，不要假设旧状态仍有效。
2. 阅读仓库中的现有项目文档与脚本，确认当前代码实际情况。
3. 先制作主角高清概念设计图，至少明确正面、侧面、背面和服装细节；发给用户确认。
4. 用户确认后再制作主角动作素材；再依次制作怪物、Boss、第一关环境、武器/药水/技能图标和战斗 UI。
5. 将正式素材真正导入 Unity，替换所有占位资源，配置动画与碰撞/受击区域。
6. 完善安卓触控 UI、屏幕比例适配、性能和本地存档。
7. 在 GitHub Actions 云端构建 APK，读取完整日志并验证 artifact。
8. 只有真实构建成功后才交付 APK。
